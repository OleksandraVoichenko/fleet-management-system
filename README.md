\# Fleet Management System



Програмна система для автоматизації управління автопарком підприємства.



\## Основні функції



\- авторизація користувачів;

\- облік транспортних засобів;

\- облік водіїв;

\- управління рейсами;

\- облік пробігу;

\- облік технічного обслуговування та ремонтів;

\- контроль планового ТО;

\- облік витрат;

\- пошук і фільтрація даних;

\- формування звітів;

\- управління користувачами та правами доступу.



\## Технології



\- Node.js

\- PostgreSQL

\- HTML/CSS/JavaScript

\- Git



\## Архітектура



Система використовує трирівневу (3-tier) клієнт-серверну архітектуру:

Presentation Layer, Business Logic Layer та Data Layer.



\## Запуск



1\. Клонувати репозиторій.

2\. Встановити залежності.

3\. Налаштувати підключення до PostgreSQL.

4\. Запустити серверну частину застосунку.
